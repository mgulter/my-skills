# My Claude Code Skills

A collection of custom Claude Code skills for enhancing AI-assisted development workflows.

## Available Skills

| Skill | Description |
|-------|-------------|
| [go-diff-linter](./go-diff-linter/) | Differential Go linting - run golangci-lint only on changed code |

## Installation

To use these skills in your project, copy the desired skill folder to your project's `.claude/skills/` directory:

```bash
# Example: Install go-diff-linter
cp -r go-diff-linter /path/to/your/project/.claude/skills/
```
